# คู่มือเริ่มใช้เจฟใน ChatGPT
ชุดนี้ยังไม่ได้สร้างหรือตั้งค่า Project ในบัญชีของคุณ เป็นไฟล์พร้อมนำเข้า ไม่ใช่การติดตั้งอัตโนมัติ

## ตั้งค่าครั้งแรกด้วยตนเอง
1. เปิด ChatGPT แล้วสร้าง Project ชื่อ “JEFF AI Support — เจฟ” ชื่อเมนูอาจต่างตามบัญชี/เวอร์ชัน
2. เปิดคำสั่งของ Project แล้วคัดลอกข้อความทั้งหมดจาก PROJECT_INSTRUCTIONS_TH.md ไปวาง
3. เพิ่มไฟล์ SKILL_REGISTRY_TH.md, ROUTING_RULES_TH.md, KNOWLEDGE_PACK_TH.md และ KNOWLEDGE_SOURCE_MAP_TH.md จากชุดนี้เป็น Project files
4. เพิ่มโฟลเดอร์ย่อย legacy_ha ใน ZIP ตามไฟล์ที่เกี่ยวข้องกับงาน ไม่จำเป็นต้อง upload โค้ด Python เพื่อสนทนา หากจำกัดจำนวนไฟล์ เริ่มด้วย 4 ไฟล์ด้านบนแล้วเพิ่มเฉพาะ master/agent briefs และแบบฟอร์มที่ใช้ ห้ามคาดว่า ChatGPT จะแตก ZIP หรืออ่านทุกไฟล์เอง จึงต้องแตก ZIP ก่อน
5. ถ้าต้องการทักษะวิจัยฉบับเต็ม ให้นำต้นฉบับ SKILL.md และ references ที่ทักษะอ้างจากแหล่งของคุณซึ่งมีสิทธิ์ใช้งานเข้ามาเพิ่มเติม URI ใน registry ไม่ใช่ลิงก์ดาวน์โหลดที่ Project อ่านได้เอง ชุดนี้มี fallback ไม่ได้บรรจุ cloud skill ฉบับเต็ม
6. ตรวจ data controls/Project memory/การแชร์ตามแผนบริการและนโยบายองค์กร ใช้ข้อมูลจำลองก่อน ไม่ใส่ข้อมูลผู้ป่วยหรือ HR อ่อนไหว หากใช้ Apps ให้เปิดและให้สิทธิ์เฉพาะบัญชี/แหล่งที่อนุญาต การมี App ในเซสชันพัฒนาไม่ยืนยันว่า Project ใช้ได้
7. เริ่มแชทใน Project นี้ พิมพ์ว่า “เจฟ ช่วยบอกไฟล์ที่อ่านได้จริงและความสามารถที่ยังขาด” อย่าถือคำตอบว่ามีไฟล์เป็นหลักฐานการใช้เครื่องมือสำเร็จจนเห็นผลตรวจจริง
8. ทดสอบ 5 สถานการณ์ตาม LIVE_ACCEPTANCE_TH.md บันทึกผลด้วยตนเองและให้ผู้รับผิดชอบตรวจ ก่อนใช้กับงานจริง

## ใช้ทุกวัน
เปิด Project เดิม พิมพ์โจทย์ตามปกติ เช่น “ช่วยออกแบบวิจัยเพื่อพัฒนาโปรแกรมลดการหกล้ม ยังไม่มีข้อมูลผล” หรือ “ช่วยตรวจแผน QI โดยแยกสิ่งที่รู้กับสิ่งที่ยังต้องยืนยัน” ไม่ต้องเลือก Agent หรือเข้า Codex
แก้ไขต่อได้ เช่น “กลุ่มเป้าหมายเปลี่ยนเป็นพยาบาลใหม่ ช่วยปรับวิธีวิจัยและระบุส่วนที่ได้รับผล” เมื่อเริ่มแชทใหม่ให้ทวนสรุปบริบทหากเจฟมองไม่เห็นข้อมูลเดิม
เจฟช่วยร่างและคิดวิพากษ์ ไม่อนุมัติ EC ไม่ออกคำสั่งรักษา ไม่รับรอง HA และไม่เก็บความรู้ระยะยาวอัตโนมัติ

## สิ่งที่ยังต้องตั้งค่า/เตรียม
- Project instructions/files และ memory/data controls โดยผู้ใช้
- ต้นฉบับ Research V4, Citation Verification และ Critical Review พร้อมสิทธิ์/รุ่น
- cloud research skills พร้อม references และแหล่งมาตรฐานปัจจุบันที่อนุญาต
- Apps/search ตามบัญชีที่มีจริง; backend เฉพาะเมื่อต้องการฐานความรู้ควบคุมสิทธิ์/audit/อนุมัติถาวรหรือเขียนระบบจริง
- ผู้รับผิดชอบทดสอบและอนุมัติใช้จริงในแต่ละงาน ไม่ถือผล offline PASS ว่า Project ผ่าน
