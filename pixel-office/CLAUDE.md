# งานส่งต่อให้ Claude Code

## เพิ่ม Codex CLI

Office รองรับ `npm run start:codex` เพื่อใช้ Codex CLI ที่ลงชื่อเข้าใช้ ChatGPT บนเครื่องรัน Windows ใช้ `npm.cmd run start:codex` หลัง `codex.cmd login` และ `codex.cmd login status` ไม่ต้องสร้าง API key สำหรับโหมดนี้ วิธีตั้งค่าอยู่ใน README.md

`lib/codex.mjs` ส่งบทบาทและโจทย์ผ่าน stdin รับกิจกรรมจาก JSON events และรับผลสุดท้ายจาก `-o` ใช้ sandbox read-only รองรับ npm wrapper บน Windows โดยเรียก Node entry โดยตรง การจัดงานและหัวหน้าทีมตรวจยังผ่าน workflow เดิม ข้อมูลใน Project หรือความจำ ChatGPT ไม่ได้ถูกโหลดอัตโนมัติ

ตรวจ syntax และทดสอบจำลอง 13 รายการแล้ว รวม Codex, การจัดงานถึงหัวหน้าทีม, สถานะผิดพลาด, การยกเลิกก่อนเริ่ม, และการค้นหา npm installation ที่มีช่องว่างใน path ยังไม่มี Codex CLI ในสภาพแวดล้อมนี้ จึงต้องทดสอบ AI จริงบนเครื่องที่ลงชื่อเข้าใช้ ไม่ถือว่าชุดทดสอบจำลองยืนยันการเชื่อมบัญชีแล้ว

คุณหน่องมอบหมายให้สร้าง Office ดร.หน่องใน GitHub ตามแนว Pixel Agents และภาพอาคารพิกเซล 6 ชั้น การรันและเชื่อม Claude จริงเป็นงานขั้นต่อไปของคุณ

## คำสั่งเริ่ม

รันจากราก repo

```bash
cd pixel-office
npm run check
npm test
npm start
```

ตรวจ `claude --version` และการลงชื่อเข้าใช้ก่อนทดสอบจริง ใช้ Claude Code ที่รองรับ `-p --output-format stream-json --verbose --include-partial-messages --json-schema --append-system-prompt --tools --allowedTools` หากรุ่นที่ติดตั้งมีสัญญา output ต่างกัน ให้แก้ adapter และเพิ่ม regression test ตามผลจริง

## โครงสร้างที่ต้องรักษา

- เจฟเป็นเลขากลาง รับโจทย์ เลือกทีม/ตำแหน่ง ติดตาม ประสาน และรายงาน
- หัวหน้าทีมแต่ละทีมรับผิดชอบงานวิเคราะห์และคุณภาพ
- คนใช้พิมพ์โจทย์ในช่องแชต ไม่ต้องเลือกทีม
- อาคาร 6 ชั้น มีโต๊ะแยกตำแหน่งและแสดงทุกบทบาท HA จากทะเบียนเดิม
- ภาพทำงานเปลี่ยนตาม event จาก workflow ห้ามใช้เวลาเดินครบเป็นหลักฐานว่างานเสร็จ
- ผลที่ต้องใช้แหล่งข้อมูลให้ขอ/อ่านหลักฐานจริง ห้ามแต่งข้อกำหนด ตัวเลข หรือแหล่งอ้างอิง
- งานแต่ละทีมใช้ Claude แยกครั้งตามบทบาท และหัวหน้าทีมตรวจอีกครั้งก่อนคืนผล ไม่อ้างเป็นบุคลากรหรือผู้ประเมินอิสระจริง

## ของเดิมที่ต้องอ่านก่อนขยาย

อ่าน `../PROJECT_CONTEXT.md`, `../docs/dialogue_learning_loop.md` และข้อมูลที่เกี่ยวข้องใน `../ha_quality_team_v2/` ก่อนเชื่อมทักษะเพิ่ม การยืนยันโครงสร้างใหม่ในบทสนทนาล่าสุดให้เจฟเป็นเลขาและหัวหน้าทีมกำกับคุณภาพ มีผลเหนือถ้อยคำ director/orchestrator แบบเดิมสำหรับ Office ใหม่นี้

Research Team Master V4 และทักษะวิจัยเดิมยังต้องยืนยันตำแหน่งต้นฉบับ อย่าสร้างทดแทนหรืออ้างว่าโหลดทักษะจาก ChatGPT แล้วโดยไม่พบไฟล์จริง ข้อมูลการเรียนรู้ต้องมีแหล่ง รุ่น และการอนุมัติตามระบบเดิม

## เกณฑ์ตรวจรับกับ Claude จริง

1. เปิด Office บน localhost และตรวจภาพที่จอกว้าง/มือถือ ชั้น 6 ลงชั้น 1 แสดงถูกลำดับ
2. พิมพ์ “สวัสดีเจฟ” ต้องได้คำตอบทั่วไปและไม่สร้างผลวิเคราะห์ขึ้นเอง
3. พิมพ์ “ช่วยทบทวน SAR ออร์โธฯ ให้หน่อย” เจฟต้องเลือกทีม HA/โต๊ะที่มีจริง หากไม่มีไฟล์ให้ถามข้อมูลเพิ่ม
4. ส่งข้อความ SAR ที่ไม่ระบุตัวบุคคล ต้องเห็นโต๊ะทำงาน แล้วหัวหน้าทีม HA ตรวจ ก่อนผลกลับเข้าแชต
5. ทดสอบอีกครั้งด้วยความเสี่ยง วิจัย EC และงานหอผู้ป่วย โดยตรวจโต๊ะกับผลจริง
6. พิมพ์คำถามต่อจากผลงาน ต้องใช้บริบทสนทนาก่อนหน้า
7. ทดลอง CLI ไม่อยู่ใน PATH หรือสิทธิ์หมด ระบบต้องแสดงติดขัดและไม่แจ้งว่าเสร็จ
8. ปิดเปิดเซิร์ฟเวอร์ ดูว่างาน/ผลยังอยู่ และงานค้างไม่แสดงว่ากำลังทำต่อเอง
9. แก้ข้อบกพร่องที่พบ รัน check/tests ซ้ำ แล้วรายงานแยกการทดสอบจำลองกับการทดสอบโมเดลจริง
10. ถ้าปรับภาพให้ตรงภาพตัวอย่างมากขึ้น ใช้อาคารแยกชั้น ลิฟต์เจฟ แสงโต๊ะปลายทาง และแชตข้างอาคาร โดยคงความอ่านง่าย

## สถานะตอนส่งต่อ

ผ่าน syntax checks และ integration tests แบบจำลอง 8 รายการ ยังไม่มี Claude executable ในสภาพแวดล้อมที่สร้างโค้ด จึงยังไม่ได้ทดสอบกับโมเดลจริงหรือประเมินภาพในเบราว์เซอร์บนเครื่องรันของคุณหน่อง

GitHub เป็นที่เก็บและแก้โค้ด รัน server ด้วย Node บนเครื่องที่มี Claude Code หน้า GitHub Pages เพียงอย่างเดียวไม่สามารถรัน child process ที่ต้องใช้ในโปรเจกต์นี้ได้

## ตัวเลือกเครื่องมือคิดและแผงสถานะ

เพิ่มโหมด OpenAI Responses API ตาม patch ที่คุณหน่องส่งมา เลือกด้วย ENGINE=openai และกำหนด OPENAI_API_KEY กับ OPENAI_MODEL ที่เครื่องรัน ค่าเริ่มต้นยังใช้ Claude Code เอกสารวิธีรันอยู่ใน README.md

แผงสถานะใช้ /api/health ตรวจเฉพาะการตั้งค่า ส่วนข้อความยืนยันได้ผลต้องอาศัยผลของงานล่าสุดที่กลับมาแล้ว การส่ง event อ่านไฟล์ระหว่างทำงานต้องไม่ล้างขั้นงานหรือป้ายสถานะ

ทดสอบจำลองผ่าน 8 รายการ รวม adapter OpenAI และการปกปิดคีย์ในข้อความผิดพลาด ยังไม่ได้ทดสอบกับบัญชี OpenAI หรือ Claude จริง
