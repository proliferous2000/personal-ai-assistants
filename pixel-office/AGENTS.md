# Office ดร.หน่อง: รายงานสถานะจากแชต

เมื่อผู้ใช้สั่งงานใน ChatGPT และต้องการให้เห็นใน Office ให้ใช้ Browser plugin ที่เชื่อมกับเครื่องผู้ใช้ หากมี ห้ามอ้างว่าเชื่อมแล้วเพียงเพราะโค้ดพร้อม

## ช่องทางที่รองรับ

- Office ต้องรันรุ่นที่มี `/api/bridge/events` และเปิดหน้า Office บนเครื่องผู้ใช้
- อ่าน Browser control skill และเอกสาร runtime ก่อนใช้งาน เลือกแท็บ Office จากรายการแท็บจริง
- ในหน้า Office เปิดรายละเอียด `รับสถานะจาก ChatGPT` ใส่ JSON ในช่อง `ข้อมูลสถานะจากเจฟ` แล้วกด `บันทึกสถานะจาก ChatGPT` ผ่าน UI ไม่ใช้ evaluate เพื่อส่ง network request หรือเปลี่ยน state
- JSON: `{taskId,eventId,title,team,desk,state,text}` ใช้ taskId เดิมตลอดงาน eventId ใหม่ต่อสถานะ อ่านชื่อ team/desk จากทะเบียนจริง ห้ามสร้างชื่อขึ้นเอง
- state ใช้ routing, working, reviewing, ready, awaiting_user, blocked ตามสิ่งที่ทำจริง ห้ามแสดงหัวหน้าทีมตรวจแล้วถ้ายังไม่ได้ทำ และห้ามรายงานว่าตัว Office เรียกโมเดลหากเป็นงานจากแชต
- ส่งสถานะเริ่ม ระหว่างขั้นที่เปลี่ยน และผลสุดท้ายเมื่อมีการทำงานจริง หน้าอื่นใน Office รับเหตุการณ์ผ่าน SSE ทันที ไม่ต้องส่งโจทย์ซ้ำเข้าโมเดล
- เมื่อไม่มีเบราว์เซอร์ที่เชื่อมหรือผู้ใช้ปิด Office ให้รายงานข้อจำกัดสั้น ๆ ทำงานหลักต่อ ห้ามอ้างว่าทุกข้อความ ChatGPT ถูกส่งอัตโนมัติ ไม่มี hook ดักบทสนทนาทั้งบัญชี
- ข้อมูล bridge เก็บใน `data/office.json` บนเครื่องผู้ใช้ ไม่ commit ข้อความ งาน หรือข้อมูลผู้ป่วยลง GitHub

## ความรับผิดชอบ

เจฟเป็นเลขา รับงาน ประสาน ติดตาม รายงาน หัวหน้าทีมเป็นผู้วิเคราะห์และตรวจคุณภาพ การทำงานใน Office และงานจาก ChatGPT ต้องระบุแหล่งให้แยกแยะได้
