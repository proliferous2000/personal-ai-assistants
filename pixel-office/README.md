# Office ดร.หน่อง

สำนักงานพิกเซล 6 ชั้นสำหรับคุยกับเจฟและติดตามการทำงานของ Claude Code จากหน้าเดียว

## รันจากเครื่องที่มี Claude Code

ต้องใช้ Node.js 22 ขึ้นไป และ Claude Code CLI ที่ติดตั้งและลงชื่อเข้าใช้แล้ว ตรวจด้วย `node --version` และ `claude --version` จาก terminal เดียวกันก่อนเริ่ม เปิด `claude` ใน repo นี้ครั้งแรกเพื่อจัดการการลงชื่อเข้าใช้และความเชื่อถือของ workspace ตามที่ Claude แสดง

จากโฟลเดอร์รากของ repo ให้รัน

```bash
cd pixel-office
npm start
```

เปิด http://127.0.0.1:3100 แล้วพิมพ์ “ช่วยทบทวน SAR ออร์โธฯ” ในช่องคุยกับเจฟ หน้าเว็บจะเลือกทีมและโต๊ะเองจากผลของ Claude ตัวละครเริ่มทำงานเมื่อเซิร์ฟเวอร์เรียกบทบาทนั้น เมื่อได้ร่างแล้วจะย้ายสถานะไปยังหัวหน้าทีมเพื่อตรวจทาน ก่อนส่งคำตอบกลับในแชต

โปรเจกต์ใช้ `claude -p` ที่เครื่องรันเป็นค่าเริ่มต้น ค่าใช้จ่ายและสิทธิ์การใช้งานเป็นไปตามบัญชีและการตั้งค่า Claude Code ของเครื่องนั้น การเปิดหน้าเว็บอย่างเดียวไม่ได้ยืนยันว่า Claude พร้อมใช้งาน ต้องส่งโจทย์และได้ผลกลับมาก่อน

ถ้าเครื่องหา executable ไม่พบ ให้กำหนด `CLAUDE_COMMAND` เป็น path ของ Claude executable ที่ติดตั้งไว้ เช่นใช้ตัวแปร environment ของ terminal นั้น หลีกเลี่ยงการตั้งเป็นข้อความคำสั่งรวม argument

## เลือกเครื่องมือคิด: Claude Code, Codex หรือ OpenAI API

ตั้งตัวแปร `ENGINE` ก่อนรัน ค่าปริยายคือ `claude`

### ENGINE=codex: ใช้บัญชี ChatGPT ผ่าน Codex CLI

**Windows PowerShell:** หลัง Pull origin ใน GitHub Desktop ให้เปิด PowerShell ในโฟลเดอร์ `pixel-office` แล้วรันทีละบรรทัด:

```powershell
npm.cmd install -g @openai/codex
codex.cmd login
codex.cmd login status
npm.cmd run start:codex
```

เปิด http://127.0.0.1:3100 และลอง “สวัสดีเจฟ” ตามด้วย “ช่วยทบทวน SAR ออร์โธฯ” ต้องได้คำตอบใน Office จึงยืนยันการเชื่อมจริง เปิด PowerShell ค้างไว้ระหว่างใช้ หากติดตั้งใหม่แล้วไม่พบคำสั่งให้เปิด PowerShell ใหม่ ตัวเชื่อมรองรับ npm บน Windows โดยเรียกไฟล์ JavaScript ผ่าน Node โดยตรง ไม่เปิด shell เพื่อส่งโจทย์

**macOS / Linux:**

```bash
npm install -g @openai/codex   # หรือวิธีติดตั้งตามเอกสาร OpenAI
codex login                    # เลือก Sign in with ChatGPT
codex login status             # ตรวจว่าล็อกอินแล้ว
cd pixel-office && ENGINE=codex npm start
```

ตัวเลือกเสริม: `CODEX_MODEL` (ชื่อโมเดลที่แพ็กเกจของคุณใช้ได้), `CODEX_COMMAND` (path ของ codex)

ข้อจำกัดที่ต้องรู้
- ต้องเป็นแพ็กเกจ ChatGPT ที่รวม Codex (เช่น Plus/Pro) และ **ไม่ใช่การเชื่อมกับแชต ChatGPT** ระบบไม่เห็น Project, GPT หรือความจำในบัญชี
- อย่าตั้ง `CODEX_API_KEY` หรือล็อกอินด้วย API key ถ้าต้องการใช้โควตาแพ็กเกจ เพราะจะคิดเงินตาม API
- เรียก `codex exec --sandbox read-only` อ่านไฟล์ใน repo ได้แต่แก้ไฟล์ไม่ได้ Codex ไม่มีช่อง system prompt ที่ตรวจสอบแล้ว ระบบจึงใส่คำสั่งบทบาทไว้หน้าโจทย์
- ทดสอบกับ Codex จำลองเท่านั้น **ยังไม่ได้ทดสอบกับ Codex จริง** รวมถึงการตีความ `codex login status` และการแสดงกิจกรรมโต๊ะ ต้องตรวจบนเครื่องที่ล็อกอินแล้ว

อ้างอิง [การลงชื่อเข้าใช้ Codex](https://learn.chatgpt.com/docs/auth) และ [codex exec / Structured output](https://learn.chatgpt.com/docs/non-interactive-mode)

### ENGINE=openai: เรียก OpenAI API

```bash
# ใช้ OpenAI API (ต้องมีคีย์จาก OpenAI Platform และกำหนดโมเดลเอง)
ENGINE=openai OPENAI_API_KEY=... OPENAI_MODEL=ชื่อโมเดลที่บัญชีคุณใช้ได้ npm start
```

ตัวเลือกเสริม: `OPENAI_REASONING_EFFORT` (ตามที่โมเดลรองรับ), `OPENAI_BASE_URL`

ข้อจำกัดที่ต้องรู้
- **นี่ไม่ใช่การเชื่อมกับแชต ChatGPT** แพ็กเกจ ChatGPT ไม่มี API ให้โปรแกรมเรียกใช้ ตัวเชื่อมนี้เรียก OpenAI API ซึ่งคิดเงินแยกต่างหาก และไม่เห็น Project, GPT, ไฟล์ หรือความจำในบัญชี ChatGPT ของคุณ ความรู้เฉพาะทางต้องส่งผ่านข้อความหรือเพิ่มเป็นไฟล์ใน repo เอง
- โหมด OpenAI **ไม่มีเครื่องมืออ่านไฟล์** อ่านได้เฉพาะข้อความในแชต (Claude Code อ่านไฟล์ใน repo ได้)
- ส่งคำขอด้วย `store:false` แต่ข้อมูลยังถูกส่งออกนอกเครื่องไปยัง OpenAI ใช้เฉพาะข้อมูลที่ปกปิดตัวบุคคลและได้รับอนุญาต
- เก็บคีย์ใน environment ของเครื่องรันเท่านั้น ห้ามใส่ในไฟล์ใน repo
- ทดสอบกับเซิร์ฟเวอร์จำลองตามเอกสาร Responses API เท่านั้น **ยังไม่ได้ทดสอบกับ OpenAI จริง**

## แผงสถานะการทำงาน

ใต้อาคารมีแผงสถานะ แสดงเครื่องมือคิด ผลตรวจการตั้งค่า (`/api/health` ตรวจเฉพาะว่าตั้งค่าครบ ไม่ได้เรียกโมเดล) ขั้นงาน 4 ขั้น (จัดงาน → ทำงาน → ตรวจทาน → ส่งผล) เวลาที่ใช้ และป้ายสถานะที่โต๊ะ บรรทัด "ยืนยันแล้ว" ขึ้นเมื่องานล่าสุดได้ผลกลับมาจริงเท่านั้น

## ไฟล์สำคัญ

- `server.mjs` ให้บริการเว็บและประวัติบน localhost
- `lib/codex.mjs` เรียก Codex CLI ด้วยบัญชี ChatGPT
- `lib/openai.mjs` เรียก OpenAI Responses API (เลือกด้วย `ENGINE=openai`)
- `lib/claude.mjs` เรียก CLI โดยส่งโจทย์ผ่าน stdin และอ่าน JSON events
- `lib/workflow.mjs` เจฟจัดเส้นทาง → ตำแหน่งทำงาน → หัวหน้าทีมตรวจ → ส่งผล
- `lib/teams.mjs` โหลดทะเบียน HA เดิมและจัดตำแหน่งในอาคาร
- `public/` ภาพอาคาร โต๊ะ ตัวละคร แชต และรายการงาน
- `CLAUDE.md` งานส่งต่อและเกณฑ์ตรวจรับสำหรับ Claude ที่จะรันต่อ

## สถานะและข้อมูล

ข้อความกับผลงานเก็บที่ `pixel-office/data/office.json` บนเครื่องรัน เก็บ 100 งานล่าสุดและบริบทสนทนา 40 ข้อความ โดยส่งบริบทส่วนท้ายไม่เกินขอบเขตต่อการเรียก Claude การเปลี่ยนเครื่องจึงต้องย้ายข้อมูลที่อนุญาตเอง ข้อมูลโฟลเดอร์นี้ถูก ignore จาก Git

เมื่อข้อมูลยังไม่พอ หัวหน้าทีมส่งคำถามกลับและงานขึ้น “รอคุณหน่องตอบ” เมื่อได้คำตอบฉบับตรวจทานจะขึ้น “พร้อมให้คุณหน่องตรวจ” หาก CLI เปิดไม่สำเร็จหรือผลไม่ครบจะขึ้น “ติดขัด” การปิดเซิร์ฟเวอร์กลางงานจะถูกระบุเมื่อเปิดครั้งถัดไป

ข้อมูลที่ส่งใน Office จะส่งต่อไป Claude Code และผู้ให้บริการตามการตั้งค่าของเครื่อง ใช้เฉพาะข้อมูลที่ได้รับอนุญาตและปกปิดตัวบุคคลแล้ว

## ตรวจสอบ

```bash
npm run check
npm test
```

ชุดทดสอบครอบคลุมการจัดเส้นทาง การตรวจโดยหัวหน้าทีม การอ่านผล CLI ความล้มเหลว งานซ้อน การบันทึกผล และการเปิดต่อหลังงานหยุด โดยใช้ CLI จำลองเพื่อไม่เรียกโมเดลระหว่างทดสอบ

การทดสอบ Claude จริงต้องทำบนเครื่องที่ลงชื่อเข้าใช้แล้ว งานที่ยังต้องตรวจบนเครื่องนั้นอยู่ใน `CLAUDE.md`

## ตัวอย่างที่ใช้ประกอบการออกแบบ

[Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents) เป็นแนวคิดต้นทางของการใช้ตัวละครและสถานะจาก AI runtime โค้ดในโฟลเดอร์นี้สร้างสำหรับอาคารแนวตั้งและโครงสร้างทีมของคุณหน่อง ใช้ภาพตัวละครที่วาดด้วย Canvas ในโปรเจกต์เอง

อ้างอิง CLI ตาม [Claude Code programmatic mode](https://code.claude.com/docs/en/headless) และ [CLI reference](https://code.claude.com/docs/en/cli-reference)

## ขอบเขตที่ต้องพัฒนาต่อ

รุ่นนี้รับข้อความและอ่านไฟล์ที่ Claude มีสิทธิ์เข้าถึงผ่านเครื่องรัน การเชื่อม Drive, ประวัติ ChatGPT, แฟ้ม skill ที่อยู่นอก repo และ Research Team Master V4 ต้องตรวจแหล่งจริงและเชื่อมเพิ่มเติม ไม่มีการรับรองว่าความสามารถเหล่านั้นติดตั้งมาพร้อมโค้ดชุดนี้

หากจะให้หลายคนใช้งานผ่านเครือข่าย ต้องเพิ่มระบบบัญชี สิทธิ์ และแยกข้อมูลผู้ใช้ก่อนเปลี่ยนการ bind เซิร์ฟเวอร์ ซึ่งขณะนี้กำหนดให้เปิดบนเครื่องรันเท่านั้น
