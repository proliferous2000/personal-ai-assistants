# Research Intelligence Team — starter scaffold

ทีม AI วิจัยสำหรับงานวิจัยการพยาบาลและงานวิจัยทางคลินิก เริ่มต้นเป็น **โครงสร้างบทบาทและ workflow** เท่านั้น ไม่ใช่ระบบ Multi-Agent ที่เรียก AI หลายตัวอัตโนมัติแล้ว

## ขอบเขต
- Research Design, R&D, RCT/GCP, สถิติและการคำนวณกลุ่มตัวอย่าง
- ทบทวนวรรณกรรมและตรวจสอบหลักฐานอ้างอิง
- IRB/EC และจริยธรรมการวิจัยในมนุษย์
- เครื่องมือวิจัย การเขียนบทความ IMRaD และตรวจทานแบบผู้ประเมินอิสระ

## ไฟล์ตรวจสอบ
- `config/agents.json` กำหนด 10 บทบาท พร้อมหน้าที่และขอบเขต
- `config/workflows.json` กำหนด 4 เส้นทางงาน (protocol, R&D, RCT, publication)

## แนวทางการใช้งานในระยะนี้
1. เลือก workflow จากคำถามวิจัยจริง
2. บันทึกโจทย์ วัตถุประสงค์ บริบทประชากร และเอกสารประกอบที่ได้รับอนุญาต
3. ดำเนินการตามบทบาททีละช่วง แยกข้อเท็จจริง ข้อเสนอ ข้อจำกัดและรายการต้องยืนยัน
4. ผู้วิจัย/ผู้เชี่ยวชาญตรวจทานก่อนยื่น EC ใช้กับผู้ป่วย หรือส่งตีพิมพ์

## ความปลอดภัยและข้อจำกัด
ห้ามนำข้อมูลระบุตัวผู้เข้าร่วมวิจัย เวชระเบียน หรือข้อมูลละเอียดอ่อนใส่ repository นี้ ห้ามอ้างว่า EC อนุมัติแล้วโดยไม่มีหลักฐาน ตรวจสอบ DOI/PMID/บทความจากแหล่งต้นทางก่อนอ้างอิง ระบบนี้ยังไม่เชื่อม API โมเดล, RAG, ฐานข้อมูลวิจัย หรือฐานข้อมูลโรงพยาบาล

## ต่อไป
พัฒนา orchestrator, schema อินพุต/เอาต์พุต, การตรวจสอบอ้างอิง, tests และจุดอนุมัติโดยมนุษย์ เริ่มจากโครงการวิจัยจำลอง/ข้อมูลนิรนามก่อน
